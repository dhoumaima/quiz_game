# QuizMaster 
QuizMaster est une plateforme web interactive permettant aux utilisateurs de tester leurs connaissances en informatique à travers des quiz.

## Fonctionnalités principales
- Choix d'une catégorie.
- Réponse à des questions à choix multiples.
- Chronomètre par question.
- Calcul automatique du score.
- Affichage des résultats et des corrections.
